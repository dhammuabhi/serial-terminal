🚀 QUICK START GUIDE
================================================================================

UBUNTU/DEBIAN:
   1. chmod +x build_deb.sh
   2. ./build_deb.sh
   3. sudo dpkg -i dist/serial-terminal_1.0.0_all.deb
   4. serial-terminal

WINDOWS:
   1. Install Python 3.8+ from python.org (with tcl/tk)
   2. Double-click build_exe.bat (or run in Command Prompt)
   3. Double-click dist\SerialTerminal.exe
   
   OR build manually:
      pip install pyinstaller pyserial
      pyinstaller --onefile --windowed serial_terminal.py

================================================================================
✨ KEY FEATURES
================================================================================

Core Features:
   ✅ Multi-window support - Open multiple serial ports
   ✅ Configurable settings - Baud rate, parity, stop bits, flow control
   ✅ Auto-scroll toggle - Toolbar button to control scrolling
   ✅ Auto-copy - Selected text automatically copied to clipboard
   ✅ Timestamps - Optional per-line timestamps
   ✅ Hex view - Display data in hexadecimal format
   ✅ Local echo - Echo sent data to terminal
   ✅ Log saving - Save terminal output to file

Advanced Features:
   ✅ Auto-reconnect - Automatically reconnects when device plugged back
   ✅ Port persistence - Remembers selected port
   ✅ Settings persistence - Saves settings between sessions
   ✅ Graceful error handling - No error dialogs
   ✅ Visual feedback - Status messages and indicators
